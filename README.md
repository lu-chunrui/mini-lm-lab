# Mini Decoder-Only Transformer

## 项目目标

使用 PyTorch 从零实现一个可训练、可生成文本的小型
Decoder-Only Transformer，并实现和测试 KV Cache。

## 当前范围

- PyTorch 张量与自动求导
- Token Embedding
- RMSNorm 与 SwiGLU
- Causal Self-Attention
- Decoder-Only Transformer
- 文本生成与 KV Cache
